# Orpheus Platformer
Hi guys! Welcome to my game! In this game, you are Orpheus - [Hack Club](https://hackclub.com)'s iconic mascot. You get to go around throughout mossy stone pathways passing fountains and trees to complete your quest. The amazing part about this game is that there is no reason to finish. There is no prize at the end. You choose what you just did. You could have saved a hackathon, making it actually happen. You could have delivered new Hack Club merch to a Hack Clubber's door. Whatever you did, it benifited the community.

## How to Play
You can play with any computer! You just need a keyboard! You use WASD or Arrow Keys to move around. If you fall and die, simply reload the page to restart and try again! The Demo Link is down below!

[Demo](https://chroma813.itch.io/orpheus-platformer)

This game is also Open Source! Simply download the source code and make changes!
